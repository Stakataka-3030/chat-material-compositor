# 聊天素材合成器

在本机浏览器中编排聊天、配置角色和手机外观，导出透明 WebM、MOV、PNG 序列及聊天长图。

Windows 10/11 x64 用户下载 Release 中的便携包，解压后双击 `聊天素材合成器.exe`。无需安装 Node.js 或下载运行组件，启动后自动打开浏览器；托盘菜单可退出软件。

源码开发需要 Node.js 22.12 或更新版本，在项目目录运行：

```sh
npm ci
npm run build
npm start
```

程序不附带游戏素材。手机界面和聊天软件可分别配置、导入／导出带素材的 ZIP，内置多种仿系统与聊天软件预设。支持自定义比例、图标、字体和文字 CSS。素材库支持本地文件、素材包、可配置在线目录和 HTTP(S) 直链。工程和导出文件保存在 `data/`。
